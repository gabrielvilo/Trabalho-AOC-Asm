# Trabalho-AOC-Asm
Conversão de Número Binário para Decimal em Assembly MIPS

Programa desenvolvido em Assembly MIPS que recebe um número binário fornecido pelo usuário
e realiza sua conversão para o sistema decimal.
A entrada é validada tanto em relação ao intervalo permitido (1 < n < 1000000000) quanto ao conteúdo,
garantindo que apenas dígitos binários (0 e 1) sejam aceitos.
Caso a entrada seja inválida, o programa solicita um novo valor até que uma entrada correta seja fornecida.

Desenvolvido para a disciplina de Arquitetura e Organização de Computadores.
